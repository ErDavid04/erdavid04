# 🚀 Sobre mí

Soy **David Garrido**, desarrollador web de 21 años apasionado por crear experiencias digitales modernas, intuitivas y eficientes.

Cuento con formación en **Sistemas Microinformáticos y Redes (SMR)** y actualmente curso **Desarrollo de Aplicaciones Web (DAW)**, lo que me permite entender tanto la infraestructura como el desarrollo frontend y backend de una aplicación desde una perspectiva completa.

Me gusta construir proyectos con una base sólida, cuidando el diseño, el rendimiento, la experiencia de usuario y la mantenibilidad del código. Siempre busco aprender nuevas tecnologías, mejorar mis habilidades y desarrollar soluciones limpias, escalables y funcionales.

* 📍 Huelva, España
* 💡 Interés en UI/UX y desarrollo frontend moderno
* 🌱 Aprendiendo JavaScript avanzado, TailwindCSS y arquitecturas escalables
* 💬 Pregúntame sobre HTML5, CSS3, Bootstrap, XML y diseño responsive
* ⚡ Apasionado por el código limpio y las interfaces modernas
